# Moggcord 1.18.66

[Documentation](../README.md) / [Release notes](README.md) / 1.18.66

## Installer

- Close everything that belongs to the selected Discord before changing it, including Moggcord helpers that run from the Discord folder, so locked files can no longer stop an installation halfway.
- Always start Discord again after installing, repairing or uninstalling. The installer now waits until Discord is really running, falls back to other ways of starting it and tells you when Discord has to be opened by hand.
- Restore Discord's original files automatically when a change fails, so Discord keeps working.
- Add Moggcord to every Discord version in the selected folder, so it is still there when Discord's new launcher starts a different version.
- Write a small `app.asar` loader next to the Moggcord folder, the same way Equicord's installer does, and stop deleting Discord's core files when an old mod changed them.
- Unpack new Moggcord files next to the old ones and swap them in one step, so a failed download never leaves Moggcord half removed.
- Log every step to `%LOCALAPPDATA%\Moggcord\installer.log`. When something goes wrong, the result page offers **Open log**.
- New look that matches moggcord.cc: Geist font, animated ASCII horizon, glowing buttons, animated Discord cards, step progress and a success animation.
