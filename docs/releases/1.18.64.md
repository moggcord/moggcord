# Moggcord 1.18.64

[Documentation](../README.md) / [Release notes](README.md) / 1.18.64

## Installer

- Streamline the setup screen and Discord selection, with channel icons for Discord and Discord Canary.
- Require a three-second hold to uninstall, with a countdown and an option to cancel by releasing early.
- Add optional automated Authenticode signing for Windows, Apple notarization for macOS and OpenPGP signatures for release checksums when signing credentials are configured.

## Downloads

Update from Moggcord settings in Discord or download the installer for your system. The macOS and Linux packages are preview builds. Technical assets and checksums are published under [updates-v1.18.64](https://github.com/moggcord/moggcord/releases/tag/updates-v1.18.64).
