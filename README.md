## Download and install

| Platform | Installer | Setup |
| --- | --- | --- |
| Windows x64 | [EXE installer](https://github.com/moggcord/moggcord/releases/latest/download/Moggcord-Installer.exe) | [Windows guide](docs/getting-started/windows.md) |
| macOS · Intel and Apple Silicon | [DMG installer](https://github.com/moggcord/moggcord/releases/latest/download/Moggcord-Installer-macOS.dmg) · Preview | [macOS guide](docs/getting-started/macos.md) |
| Linux x64 | [AppImage](https://github.com/moggcord/moggcord/releases/latest/download/Moggcord-Installer-Linux.AppImage) · [DEB](https://github.com/moggcord/moggcord/releases/latest/download/Moggcord-Installer-Linux.deb) · Preview | [Linux guide](docs/getting-started/linux.md) |

1. Install Discord and download the matching Moggcord installer.
2. Open the installer, select the Discord channel you use (**Stable**, **PTB**, or **Canary**) and choose **Install Moggcord**.
3. Reopen that Discord channel and find **Moggcord Settings** in User Settings.

For an existing installation, the installer also offers **Repair Moggcord** and **Uninstall Moggcord**. [Full installation guide](docs/getting-started/installation.md)

| Feature | Where to start |
| --- | --- |
| **Plugins** | Search bundled plugins, toggle the ones you want and adjust individual settings. [Plugin guide](docs/guides/plugins.md) |
| **Themes and QuickCSS** | Load local or online themes and fine-tune CSS from the quick actions. [Theme guide](docs/guides/themes.md) |
| **Community uploads** | Browse shared plugins and themes. Set up the local connector for website-driven plugin installs. [Community guide](docs/community/setup.md) |
| **Updates and backups** | Check for updates in Discord and export your preferences before moving to another machine. [Updates and repair](docs/guides/updates-and-repair.md) · [Backup and restore](docs/guides/backup-and-restore.md) |
